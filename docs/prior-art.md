# Prior art

## Prior art looked at (pages fetched 2026-10-28)
- ESPresense (https://espresense.com/): fingerprint-based IDs, IRK enrollment for Apple devices, median pre-filter + 1 Euro filter on distance. We already use IRK; the median/1 Euro filter on RSSI is not copied yet.
- Bermuda BLE Trilateration (https://github.com/agittins/bermuda): HA integration over ESPHome proxies.
- Espressif Wi-Fi API guide (https://docs.espressif.com/projects/esp-idf/en/v4.4.7/esp32c3/api-guides/wifi.html): modem-sleep modes.
- room-assistant and the ESPHome bluetooth_proxy page were not mined for coex settings (no relevant text found on the proxy page).
